1. Use the **Sticker pop** design (not Fresh market).
2. Add the **flip-through book** view for recipes, if it is not already there.
3. The **Week** view should show more information per day, like design option **#3** did.
4. New tab: **"Runi og child"**, a place to add Runi Lee's own recipes.
   - Store each child's **birthday** so the app knows the child's age.
   - Tag child recipes with the **age** they fit, so they can be reused for the next child at the same age.

6. The app **analyses the week** against the rules. If a rule is missed (e.g. no fish), it **suggests swaps** using recipes already added.
